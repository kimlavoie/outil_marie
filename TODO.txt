Suggestions d'amelioration (analyse du 2026-07-12, 2e passe)

PRIORITE MOYENNE - qualite, CI et accessibilite
- Couverture de tests tres inegale sur les composants Settings :
  src/components/settings/*.tsx (rooms, salaries, services, accounts,
  pricing-grid-editor) ont 2 a 15% de couverture de lignes, alors que
  c'est la que l'utilisatrice configure les donnees de base (salles,
  tarifs, salaires). Une regression y serait silencieuse jusqu'a
  l'usage reel.
- Accessibilite minimale des formulaires : seulement 14 occurrences
  d'aria-* dans tout src/, et plusieurs formulaires Settings
  (common.tsx, linked-sections.tsx) n'ont aucun <label> associe. Pour
  une utilisatrice dependant potentiellement d'un lecteur d'ecran ou
  du zoom navigateur, les champs sans label explicite sont un vrai
  obstacle.
- Aucune documentation utilisateur : pas de README.md a la racine ni
  ailleurs. Rien n'explique a l'utilisatrice non-technique comment
  configurer la sauvegarde automatique, ce qu'est le File System
  Access API, ou comment restaurer une sauvegarde en cas de probleme.
  test/SMOKE_TEST_CHECKLIST.md existe mais c'est un doc de dev, pas
  utilisateur.
- Bundle principal non code-splitte : le chunk index-*.js fait 686 KB
  (187 KB gzip) et Vite avertit du depassement de 500 KB. xlsx-viewer
  et pdf-viewer sont deja separes, mais settings/activites/dashboard
  restent dans un seul chunk ; un import() dynamique par vue
  reduirait le temps de premier chargement.

PRIORITE BASSE - dependances et robustesse navigateur
- Dependance xlsx tiree d'un CDN externe non-npm : package.json:42
  pointe vers https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz.
  Cette dependance critique (import/export du grand livre) n'est pas
  sur le registre npm, sans hash d'integrite verifiable ; en cas
  d'indisponibilite du CDN, "npm ci" echoue.
- pdf.worker.min.mjs de 1,25 MB non compresse dans le build : ne
  figure pas dans le rapport gzip de Vite ; a verifier si GitHub Pages
  le compresse correctement, sinon impact sur le premier chargement du
  visualiseur PDF.
